The real #276 run completed article 21027 and sealed two UNCERTAIN horizon
records. That is a legitimate abstention, not an observed forecast error.

Enable the new candidate inference path by adding `--event-aware` to the
documented forward_news_market_cycle_cli command and selecting a new output
filename. Existing completed articles are not reprocessed or resealed.
The local original-news archive supplies up to three title-overlap candidates
whose publication, detection and body observation predate current publication.
Candidate retrieval is bounded and incomplete; absence is not evidence of
novelty. Gemma selects candidate links, not authenticated event families.

The new schema preserves source quotes, separates economic meaning from
market direction, and requests independent 1/5-session forecasts. The original
hash-chain record and same daily-price anchors remain unchanged. The committed
evaluator checks each horizon against the matching original model output.
Legacy single-direction retrospective evaluation excludes dual forecasts.

No price data is provided to the model; no rule promotion, model training,
new evaluation horizons, intraday scoring changes, or unattended activation.
CI fixtures are synthetic. A real Mac run and future observed prices are
required before measuring forecast performance. Independent source-clock
authentication, full event-family validation, and paired holdout comparisons
remain outstanding.

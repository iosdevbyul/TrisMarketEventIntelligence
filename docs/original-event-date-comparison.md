# Original event date comparison

PR #284, after 12 original hypotheses yielded zero mature observation-date outcomes. New separate read-only CLI original_event_date_comparison_cli verifies the original v1 seal and compares its unchanged directions with price windows anchored on SEC acceptance or publisher-declared time. No Gemma calls. Missing/inconsistent clocks are blocked, never replaced with capture time. Price coverage dates and lag are reported. Entry is first later exchange-local benchmark close, horizons 1/5 subsequent observed benchmark sessions, stock bars required throughout. A history beginning after anchor is rejected; independently verified exchange calendar is not available. This does not measure the immediate announcement reaction. Crucially the original predictions were generated later and had observation-date semantics: reanchoring is a descriptive sensitivity comparison, not original forecast accuracy or authenticated historical replay. Historical source version, mapping availability, causal attribution and training eligibility remain unverified. No seal or source data changes. Run --seal existing-file --prices existing-adjusted-daily.csv --output new-file, optional --price-manifest. No new prediction generation.

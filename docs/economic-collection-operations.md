# Economic collection operations

Core collection is not a claim of complete global history. The Mac run validated 102 numerical series, BEA historical discovery, persisted quota cooldown, selective release capture and 440 registered OCR pages. Publication-time verification, completeness and visual review remain open.

Use the global collector with --operational for incremental core refresh, seven-day release reuse and current listings. Add --watch --interval 3600 for a foreground loop. An omitted --end rolls forward each cycle. No OCR is invoked in operational mode. Known blocked release sources are listed in deferredSources and can be tried explicitly with --release-source. The two unconnected China sources remain explicit gaps. A deferred source is not a successful source.

Use economic_inventory_cli with --news-db, --macro-db, optional --ocr-db and a distinct --output path to report actual persisted data without network calls. Counts are stored rows (including revised numerical values), not unique market events or verified historical vintages. OCR evidence rows may include multiple engine configurations. Missing publication dates and absent tables are reported, not synthesized.

Do not start a second collector against the same databases while an existing collector is active. No service is installed or started by this change. No Gemma inference, price validation or analysis is included.

# AI event profile integration

PR #284. Real semantic v1 baseline: 20 calls, 9 unrelated, 11 rejected, zero useful links. New profile-first workflow uses pinned sources and existing local LLM runtime, reusable content-keyed profiles, actor/type/period/fact retrieval, capped pair reviews, evidence IDs rather than generated quotations, and specific error codes. Existing review ledger is preserved. New tables are independent, no collection changes. Profile facts and selected evidence remain model hypotheses, not entailment verification. A bounded sample can contain no true matching pairs; no positive count forced. Initial profile budget 30, review budget 10. Existing automatic news impact analyses are not directly reused because their output contract does not guarantee primary actor/action/period; existing source verification and runtime are reused instead. No model promotion or prediction eligibility.

Run module event_profile_integration_cli with --news-db, --event-db, --run-id, --model gemma4:e2b, --profile-limit 30, --review-limit 10, --execute. Omit --execute for preview. Repeated runs reuse content-identical profiles, including rejected records. Compare actual positive and negative results before accepting; current cross-language actor normalization is limited and period matching conservative.

# Learning-03 — news-only importance probability evaluation

This component evaluates **news importance judgments only**. No stock prices,
OHLCV, realized market returns, volume, or price outcomes are read, fetched,
trained on, scored or inferred. Direction, intensity, duration and uncertainty
of **conditional news pressure** are separate hypotheses; Learning-02's human
importance-only labels cannot truthfully score those dimensions yet.

## What to evaluate

Given one historical all-news cohort JSON exported by Learning-01, one
manually completed human-importance review JSON from Learning-02, and one
provenance-pinned model probability JSON, compare:

- How often the model calls important news important (precision, recall)
  and flags ordinary human-UNIMPORTANT stories (false-important rate).
- Three-class macro F1 and overall categorical accuracy.
- Multiclass Brier (mean of squared class errors) and log loss, against
  a simple **always UNIMPORTANT** baseline evaluated on the **same human
  labeled set**. Neither the baseline nor labels are generated by the AI.
- Exclusions for unreviewed/UNCERTAIN human labels and for predictions
  generated after a human review was available.

The model must supply an **explicit distribution** for all three classes
(`IMPORTANT`, `UNIMPORTANT`, `UNCERTAIN`), with finite probabilities in
[0,1] summing to 1. The model output document uses:

```json
{
  "schemaVersion": "news_importance_probabilities_v1",
  "cohortSha256": "<sha256 of original cohort bytes>",
  "modelId": "local-news-classifier",
  "promptVersion": "importance-v1",
  "generatedAt": "2026-11-15T12:00:00+09:00",
  "predictions": [
    {
      "articleId": 1,
      "textSha256": "<exact archived article hash>",
      "probabilities": {
        "IMPORTANT": 0.25,
        "UNIMPORTANT": 0.65,
        "UNCERTAIN": 0.10
      }
    }
  ]
}
```

Values are a **format example**, not observed model output. Every original
cohort article, including unclassified / ordinary news, needs exactly one
prediction row. All IDs, original text hashes, model identity and cohort SHA
are checked. Posthoc edits or duplicates fail closed. No inference call
or model retraining occurs here.

## How to test locally only when needed

The same Mac script is already modified; do not invent another command
workflow or require it to run just to pass CI.

```sh
bash scripts/news-learning-review.sh --update evaluate \
  --cohort /private/cohort-v2.json \
  --review /private/human-reviewed.json \
  --predictions /private/model-probabilities.json \
  --output /private/news-importance-evaluation-new.json
```

The script resolves the installed project Python after the optional
clean-main fast-forward and writes a **new** private JSON report, never
overwriting or uploading sources.

## Validity boundaries

A group of fewer than 100 scored human judgments reports
`INSUFFICIENT_HUMAN_GOLD`, with descriptive metrics but **no quality
certification**. Reaching 100 reports `DESCRIPTIVE_ONLY_NOT_VALIDATED`,
not a statistical guarantee. Human-provided reviewer identities and
labels are not independently authenticated. A common `generatedAt`
timestamp after any labeled review excludes those articles rather than
claiming a prelabel prediction. Independent holdout and group/time leakage
audits are still required before any real improvement can be certified.

Evaluation never modifies the source database or journal, never applies
models to production, and never trains automatically. Future improvements
must use separate, independently assessed news pressure hypothesis labels
for conditional direction/intensity/horizon, and ensure trained candidates
were not exposed to the evaluation set.

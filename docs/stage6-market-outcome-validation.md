# Stage 6: Gemma original article outcome validation

This research command joins **existing** `gemma_original_article_review_v2` JSON artifacts to **sourced historical adjusted-close data**. It neither rewrites the production SQLite database nor triggers Ollama, collectors, timers or trading.

## Required input

- `--gemma-dir`: existing `main-validation-gemma` results generated by `gemma_original_article_batch_cli`. Only successful article JSON files belong here. The file-level SHA-256 of every prediction is preserved in the output.
- `--mappings`: CSV with columns `target,market,symbol,benchmark,verified_at`. Targets must exactly match the Gemma-generated target string; `market` is XKRX, XNAS or XNYS; `verified_at` must be a timezone-aware date when the mapping is demonstrably supported by records available at that time. Do **not** backdate mappings to make a historical evaluation succeed.
- `--prices`: CSV with `symbol,date,adjusted_close,source`, one row per symbol and trading date. `source` must identify the actual data provider / export. Populate with genuine, authorized historical observations, not generated or placeholder prices. Include both subject and benchmark adjusted closes for the entry date and future dates.
- `--price-source`: human-readable dataset identification and coverage/version.
- `--output`: new JSON filename. Existing output is never overwritten.

Example:

```bash
DATA="$HOME/Library/Application Support/TrisMarketEventIntelligence"
python -m tris_market_event_intelligence.market_outcome_validation_cli \
  --gemma-dir "$DATA/main-validation-gemma" \
  --mappings "$DATA/stage6-verified-target-map.csv" \
  --prices "$DATA/stage6-actual-adjusted-daily.csv" \
  --price-source "provider/export/version and capture date" \
  --output "$DATA/stage6-outcomes-v1.json"
```

This is a **daily-bar validation bridge**: 1- and 5-trading-session returns, benchmark-relative returns, per-impact CORRECT/INCORRECT/ABSTAINED/UNAVAILABLE status and coverage counts. A daily entry is the first available session close on a date strictly after the article's **exchange-local** publication date. Missing days are not filled. Outcomes may miss immediate intraday reactions. For 1-hour and minute reactions, use the separate intraday research pipeline after source-specific coverage and an authenticated session calendar are provided.

The direction deadband is ±0.1% of *absolute adjusted return*; benchmark-relative returns are reported separately and are not retroactively chosen as the scoring basis. This rule must be fixed before looking at evaluation labels.

## Important epistemic limits

The existing article batch explicitly sets `predictionSealedBeforeOutcome=false`. These outputs remain **RETROSPECTIVE_UNSEALED**, regardless of whether subsequent label directions happen to match. Hashing them today proves integrity from today forward, not that a historical prediction existed at publication time. They must never be represented as prospective historical forecasting accuracy or a causal effect of news.

Target mappings with `verified_at` later than publication are explicitly marked `RETROSPECTIVE_POST_EVENT_MAPPING` and remain research-only comparisons; they must never be counted as point-in-time prospectively verified forecasts. Unmapped targets are separately reported. The daily study is descriptive and does not remove market confounders beyond the simple benchmark comparison. A stronger validation requires a point-in-time historical replay, proper external test period, independent source availability audit, and comparison against naive market baselines.

An optional Yahoo Finance research adapter is available below. It is not an institutional subscription or a point-in-time archive. The 2026-11-21 BNS pilot retrieved 26 BNS/SPY historical daily price observations and produced one matched direction: BNS +0.33% (SPY -0.48%) after one session, and BNS -2.21% (SPY -2.70%) after five sessions. Absolute directional verdicts were CORRECT then INCORRECT, while relative returns were positive at both horizons. This is one retrospectively generated, unsealed sample, **not** a prospective accuracy measurement.

## Real observed daily prices: optional Yahoo research adapter

Install `python -m pip install yfinance` only if using Yahoo Finance. `yfinance` is a third-party unofficial research interface, not a licensed institutional feed. It may reject requests or revise adjusted prices; such failure means missing data, never zero return. Source: https://ranaroussi.github.io/yfinance/reference/yfinance.price_history.html

Create a source-verified, intentionally small pilot target map for the one unambiguous publicly traded company in this batch. The Bank of Nova Scotia was listed on NYSE under **BNS** before the article date, as documented in 2026 SEC disclosures: https://www.sec.gov/Archives/edgar/data/9631/000119312526364091/d143422dex991.htm . SPY is a broad US market comparison benchmark, not a representation of BNS's sector. Here `verified_at` is the **date when the analyst confirmed the mapping**, NOT a fabricated historical date. This is still an **unsealed retrospective evaluation**.

```bash
DATA="$HOME/Library/Application Support/TrisMarketEventIntelligence"
python - "$DATA/stage6-verified-target-map.csv" <<'PY'
import csv, sys
from datetime import UTC, datetime
from pathlib import Path
path = Path(sys.argv[1])
if path.exists():
    raise SystemExit("Mapping file already exists; refusing overwrite")
with path.open("x", newline="", encoding="utf-8") as output:
    writer = csv.writer(output)
    writer.writerow(["target", "market", "symbol", "benchmark", "verified_at"])
    writer.writerow(["The Bank of Nova Scotia (BNS)", "XNYS", "BNS", "SPY", datetime.now(UTC).isoformat()])
print(path)
PY

python -m pip install yfinance
python -m tris_market_event_intelligence.market_price_collection_cli \\
  --mappings "$DATA/stage6-verified-target-map.csv" \\
  --start 2026-10-27 --end 2026-11-13 \\
  --output "$DATA/stage6-actual-adjusted-daily.csv"

python -m tris_market_event_intelligence.market_outcome_validation_cli \\
  --gemma-dir "$DATA/main-validation-gemma" \\
  --mappings "$DATA/stage6-verified-target-map.csv" \\
  --prices "$DATA/stage6-actual-adjusted-daily.csv" \\
  --price-source "Yahoo Finance via yfinance, sourced Nov 2026 adjusted daily history" \\
  --output "$DATA/stage6-outcomes-v1.json"
```

This pilot only evaluates the exact BNS target string. Other target strings remain `UNMAPPED`; that is intentional. Even if all returned price rows are real, a directional match does **not** identify the Fed article as the cause. The command output gives the path to a per-impact report; inspect the BNS item and the coverage first. For later pilots, add only unambiguously identified securities or **explicitly labeled** sector ETF proxies with documentary provenance and state their semantic mismatch. Do not turn inflation, GDP, Treasury yield levels, or mixed multi-entity targets into one equity symbol.

## Reproducible, explicitly qualified sector proxy cohort

The exact-target allowlist contains the directly identifiable BNS equity and **qualified** US sector ETF proxies: XLK for Technology, XLE for Energy, XLF for Banking (not banks-only), IYG for US Financial Services, and IPAY for digital Payment Services. Source identification: [State Street Select Sector ETFs](https://www.ssga.com/us/en/individual/capabilities/equities/sector-investing/select-sector-etfs), [iShares IYG](https://www.ishares.com/us/products/239509/ishares-us-financial-services-etf), [Amplify IPAY](https://amplifyetfs.com/ipay/). The proxy catalog is explicit and exact-string only, not an open-ended symbol inference. Unclear macro targets such as inflation, GDP, yields, global markets, composites or private organizations stay **unmapped**. A proxy is an imperfect sector representation, never the exact economic claim made by the model.

## Intermittent data-provider outage: reproducible missing-symbol recovery

On 2026-11-22, a second Yahoo Finance fetch used an extended end-exclusive date
`2026-11-22` and returned **774 rows** for six instruments but flagged
`missingSymbols=["BNS"]`. Yahoo's generic "possibly delisted" diagnostic is
**not confirmation of an exchange delisting**. The prior v2 source file had
**896 rows** and included previously observed BNS quotes. Accordingly, v2
and v3 directional accuracy are **not directly comparable**: one previously
correct BNS impact vanished from the v3 sample; the five-session horizon
became available for some later November publications.

Do not re-request or overwrite the original immutable files. Recover missing
BNS instrument observations from the preserved v2 export, using the latest
v3 export for all instruments that v3 successfully retrieved. The recovery
will **never** mix primary/fallback datasets within the same symbol, fabricate
missing trading sessions, or claim the merged output was one provider snapshot.
Its manifest lists SHA256 hashes of every source, selected source per symbol,
row counts, and incomplete-date-coverage disclaimer.

```bash
DATA="$HOME/Library/Application Support/TrisMarketEventIntelligence"

python -m tris_market_event_intelligence.market_price_recovery_cli \\
  --primary "$DATA/stage6-sector-prices-v3.csv" \\
  --fallback "$DATA/stage6-sector-prices-v2.csv" \\
  --mappings "$DATA/stage6-sector-target-map-v2.csv" \\
  --output "$DATA/stage6-sector-prices-v4-recovered.csv"

python -m tris_market_event_intelligence.market_outcome_validation_cli \\
  --gemma-dir "$DATA/main-validation-gemma" \\
  --mappings "$DATA/stage6-sector-target-map-v2.csv" \\
  --prices "$DATA/stage6-sector-prices-v4-recovered.csv" \\
  --price-source "Yahoo Finance via yfinance; v3 primary and BNS v2 recovery, per-symbol lineage manifest" \\
  --output "$DATA/stage6-sector-outcomes-v4.json"
```

Inspect `stage6-sector-prices-v4-recovered.csv.manifest.json` for
`recoveredSymbols=["BNS"]`, `completeInstrumentCoverage=true`, and
`completeDateCoverageGuaranteed=false`. The last flag means an instrument
might still lack sessions near the end. Do not claim full-horizon accuracy
without verifying each per-impact `dataStatus`. This operation does not
change Gemma predictions or prove market impact causality.

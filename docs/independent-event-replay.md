# Independent event source-observation replay

PR #284: no cross-source match prerequisite. Two separate commands: forecast consumes pinned article bodies, source facts, existing reviewed mapping CSV, local Gemma; evaluate consumes the resulting hash-sealed file and existing real adjusted closes. Forecast does not accept prices or later linked news. Output is create-only. Hash seal is local integrity, not proof of historical or prospective timestamp. Historical observation anchor is the latest pinned source observation, not independently verified first public. Current mapping knowledge may postdate the historical observation; not a PIT-verified mapping. Model pretraining and source content may already contain historical outcomes; no authenticated prospective claim. Exact title name/SEC issuer mappings only; unmapped economic events are explicitly skipped. One target per source, bounded round-robin; multi-target/sector mapping and structured semantic metric extraction remain incomplete. Price labels use exchange-local later benchmark sessions, require aligned stock bars, no independently verified complete exchange calendar. Report actual absolute and excess returns with separate verdicts; no causal attribution or training promotion. No source databases modified.

Run independent_event_replay_cli forecast --news-db ... --event-db ... --run-id ... --mappings reviewed-mappings.csv --model gemma4:e2b --limit 12 --output new-seal.json; then evaluate --seal new-seal.json --prices expanded-adjusted-daily.csv --output new-outcomes.json. Optional --price-manifest validates dataset hash. No new live collection or activation.

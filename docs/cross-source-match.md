# Cross-source event matching v1

PR #284; previous hybrid diagnostic 4/4, but zero independent positive controls. This opt-in scanner uses all admitted pinned article bodies, explicit comparable metric keys (country, indicator, core/headline, period, change basis, signed value), and limited SEC issuer/event cues. A missing year inferred from declared publication is marked non-explicit; no first-public claim. Board records without declared times can match only strong metric keys. Same raw original is excluded. Candidate rows and separate AI reviews are persisted; no automatic event promotion, trading or price evaluation. Exact metric agreement is a candidate, not proof of event identity or independent editorial corroboration. Conservative parsing abstains on ambiguous periods, expected values, mixed metrics or directions; limited coverage is expected. Initial supported series are US PCE/GDP/CPI/PPI and Korean CBSI/CCSI; SEC cues cover earnings and executive reinstatement. This does not verify original vintage values or parse every document layout. Prior logs provide no confirmed independent positive pair; inspect actual retrieved candidates before labeling and evaluating recall. Fixture tests are not real accuracy.

Run module cross_source_match_cli with --news-db, --event-db, --run-id, --model gemma4:e2b, --limit 10, --execute. Without execute preview is read-only, no AI calls. Existing collectors and prior ledgers unchanged.
